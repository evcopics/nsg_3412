# ChurchCaption

Windows·macOS용 교회 예배 자막 프로그램입니다.

## 다운로드

최신 설치본은 [Releases](https://github.com/evcopics/nsg_3412/releases)에서 받으세요. 1.0.54부터 앱 내 업데이트 확인·알림·다운로드·설치를 지원합니다. 최초 한 번은 새 설치 파일을 직접 실행해야 합니다.

새 버전 확인은 앱 실행 후와 매시간 진행하며, 도움말 → 업데이트 확인에서 직접 확인할 수도 있습니다. 송출 중에는 설치를 보류하고 변경 자료를 저장한 뒤 앱 종료 후 설치 창을 엽니다. 설치는 사용자가 선택합니다.

Windows와 Mac(Intel / Apple Silicon)을 지원합니다. NDI를 포함하고, 정상 설치된 Runtime의 재설치는 생략합니다. 사용 방법은 앱 도움말을 참고하세요.

GitHub 공개 기간 이후에도 설치된 앱은 ONEVCO의 서명된 업데이트 경로를 사용합니다. GitHub 비공개 전환은 이미 내려받은 앱의 실행을 막지 않습니다.

앱 소스 코드와 사용자의 CC 예배 파일·설정은 이 저장소에 공개하지 않습니다.
